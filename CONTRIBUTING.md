# Правила оформления коммитов (Conventional Commits)

Мы используем стандарт Conventional Commits. Сообщение коммита должно быть в формате:

`<тип>: <краткое описание>`

### Основные типы:
- **feat**: новая функциональность (например, `feat: add division function`)
- **fix**: исправление ошибки (например, `fix: resolve merge conflict`)
- **docs**: изменения в документации (например, `docs: update README`)
- **ci**: изменения в CI/CD (например, `ci: add GitHub Actions workflow`)
- **refactor**: рефакторинг кода
- **test**: добавление или изменение тестов

Пример: `feat: add calculator class with basic math operations`
